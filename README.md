**SmartTask AI**

Un gestionnaire de tâches intelligent qui exploite l'IA pour transformer vos objectifs vagues en plans d'action concrets et hiérarchisés.

**📌 Présentation**

**SmartTask AI** est une application Python conçue pour résoudre le problème de la procrastination face à des tâches complexes. En intégrant l'API OpenAI, l'application analyse une tâche principale et génère automatiquement une arborescence de sous-tâches logiques, hiérarchisées et immédiatement exécutables.

**✨ Fonctionnalités**

* 🧠 **Décomposition Intelligente :** Utilisation de GPT-4o pour segmenter une tâche complexe en étapes simples.
* 📊 **Priorisation Automatique :** L'IA évalue l'ordre logique de réalisation pour optimiser votre flux de travail.
* 🛠️ **Gestion Complète :** Système CRUD complet pour suivre l'état d'avancement (En cours / Terminé).
* 🔒 **Sécurité :** Gestion rigoureuse des clés API via des variables d'environnement (.env).
* 🧪 **Qualité de Code :** Suite de tests unitaires avec pytest et formatage strict avec black.

**🛠️ Stack Technique**

* **Backend :** Python 3.10+
* **IA :** OpenAI API (Modèles GPT-4o / GPT-3.5-turbo)
* **Qualité :** Pytest, Black
* **Gestion d'environnement :** Virtualenv / Venv

**🚀 Installation & Configuration**

**Prérequis**

* Python 3.10 ou supérieur
* Une clé API OpenAI active
